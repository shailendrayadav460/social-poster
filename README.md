# ✦ Poster Studio — Social Card Maker

A beautiful, browser-based poster & social media card maker. No sign-up, no install — just open and create.

---

## 🚀 How to Use

1. **Open** `poster-maker.html` in any browser
2. **Upload** your image (PNG, JPG, WEBP, GIF)
3. **Customize** background gradient, text, colors
4. **Paste** formatted text directly from ChatGPT or anywhere
5. **Download** your card as PNG, JPEG, or WEBP

---

## ✨ Features

- 🖼️ Upload any image with fit controls (Cover / Contain / Stretch)
- 🎨 8 gradient presets + fully custom color picker
- ✍️ Rich text paste support — bold, lists, headings all render on card
- 🎯 Text position control (Top / Center / Bottom)
- 🌈 Individual color pickers for title & subtitle
- ⬇️ High-res export (3× scale) for crisp social media quality
- 💅 Attractive card with 3% border radius & gradient border

---

## 🛠️ Tech Stack

- Pure HTML, CSS, JavaScript — zero dependencies
- [html2canvas](https://html2canvas.hertzen.com/) for card export
- Google Fonts — Playfair Display + DM Sans
